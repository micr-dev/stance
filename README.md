# On AI

A plain-text website collecting Microck's stance on AI and answers to recurring
arguments about its use.

## Local development

Build the page:

```sh
bun run build
```

Serve it on port 4173:

```sh
bun run serve
```

The site has no client-side JavaScript and no runtime dependencies.

## Assets

The page self-hosts the Latin subset of Inter. Its SIL Open Font License is
included at [`assets/fonts/OFL.txt`](assets/fonts/OFL.txt).

`assets/robot.svg` is based on
[Robot icon.svg](https://commons.wikimedia.org/wiki/File:Robot_icon.svg) by
